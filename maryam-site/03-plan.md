## تکنولوژی (هم‌راستا با تصمیم قبلی‌ات برای سایت خودت)
- **Astro + Tailwind CSS** — سایت استاتیک، خیلی سریع، چندزبانه ساده (`/en` و `/fa`).
- **فونت Vazirmatn** (self-hosted، برای فارسی) + یک فونت لاتین هم‌خانواده.
- **هاست: لیارا** (ایرانی؛ برای بازدیدکننده داخل ایران سریع است).

> **توضیح — سایت استاتیک:** یعنی صفحه‌ها یک بار موقع build به HTML آماده تبدیل می‌شوند و سرور فقط فایل تحویل می‌دهد؛ دیتابیس و بک‌اند ندارد. نتیجه: سریع، ارزان، امن، و برای یک سایت رزومه کاملاً کافی.
>
> **توضیح — i18n:** مخفف internationalization (۱۸ حرف بین i و n). یعنی زیرساختی که یک سایت چند زبان داشته باشد؛ اینجا یعنی هر متن یک نسخه فارسی (راست‌به‌چپ) و یک نسخه انگلیسی (چپ‌به‌راست) دارد.

## طراحی صفحه تماس — منطق
- **ایمیل اول**، با دکمه کپی (ریکروترها ایمیل می‌فرستند، فرم پر نمی‌کنند).
- **بدون فرم در نسخه ۱**: فرم بک‌اند لازم دارد، ممکن است اسپم بگیرد، و سرویس‌های خارجی فرم از ایران ناپایدارند. اگر خواستیم، بعداً با سرویس Formy (پروژه ابوالفضل) اضافه می‌کنیم.
- لینکدین + دانلود رزومه + منطقه زمانی + «معمولاً ظرف ۲۴ ساعت پاسخ می‌دهم» (کاهش تردید).

## اجرای محلی قبل از دیپلوی — چه چیزی نصب کنی
1. **Node.js نسخه LTS** (همان نسخه‌ای که nodejs.org با برچسب LTS پیشنهاد می‌دهد) — همراهش npm نصب می‌شود.
2. **Git** (برای نسخه‌بندی و بعداً دیپلوی).
3. (اختیاری) **VS Code** برای دیدن کد.

بعد از اینکه پوشه پروژه را ساختیم و به من وصلش کردی:
```bash
npm install      # یک بار، نصب وابستگی‌ها
npm run dev      # اجرا؛ سایت روی http://localhost:4321 باز می‌شود
```
> **نکته:** برای اینکه من مستقیم روی سیستمت فایل‌ها را بسازم، در اپ دسکتاپ Claude یک پوشه (مثلاً `Documents/maryam-site`) را با دکمه «Add folder» به این گفتگو وصل کن.
